# Cape Cod Sites

Affordable, professional websites for Cape Cod businesses.

## Packages
- **Starter Site** — $499: 5 pages, mobile-friendly, contact form, basic SEO
- **Business Site** — $799: Up to 8 pages, booking/menu, gallery, stronger SEO
- **Care Plan** — $79/month: Hosting, updates, security, support

## Quick Start
1. Replace the placeholder email in `index.html` with your real email.
2. Host for free on GitHub Pages, Netlify, or Vercel.
3. Buy a domain (capecodsites.com or similar) and point it at the host.
4. Start outreach to local businesses.

## Files
- `index.html` — Main landing page
- `README.md` — This file
- `outreach.md` — Pitch email templates and process
- `clients.csv` — Simple lead/client tracker

Start as a sole proprietor in Massachusetts. Form an LLC later once revenue justifies the $500 filing + $500 annual fee.
